- hubmcp: optional. The admin tools may surface the header's request id.

### Contract notice — HUB-283 (CCR-002) — hub-admin.v1.yaml 1.1.0 (minor, same pending release)
- Changed: `listIntegrations` (`GET /admin/v1/integrations`) takes optional boolean query parameters `has_active_version` and `active_version_behind`.
  - `active_version_behind=true` means an active version exists and either `latest_version > active_version` or `has_draft`.
  - `false` means the active version is the latest and there is no draft.
  - Integrations without an active version match neither value.
  - Filters combine with AND and apply before pagination. A non-boolean value gives `VALIDATION_FAILED`.
- operationIds affected: `listIntegrations`.
- Backend: implement both filters in the registry query, server-side and before the cursor. Extend the `listIntegrations` contract test with both parameters.
- Frontend: `npm run gen:api`. In `routes/(app)/integrations`, add the filter (URL params and chips) and remove `TODO(CCR-002)` in `filters.ts`.
- hubmcp / skill: no change.

### Contract notice — HUB-284 (CCR-003) — hub-admin.v1.yaml 1.1.0 (minor, same pending release)
- Changed: `AccountSummary` (`listAccounts`) and `Account` (`getAccount`) gain optional `dead_letter_count` (integer ≥ 0) and `dead_letter_oldest_at` (date-time or null). They count dead letters whose last attempt used the account, not replayed, within the 14-day retention. They may lag by up to a minute. Examples: `ct-brandA-in` has 1, `ct-brandA-in-v2` has 0 and null.
- operationIds affected: `listAccounts`, `getAccount` (and every response that embeds `Account`, where the fields are optional).
- Backend: fill both fields from the DLQ store on `listAccounts` and `getAccount`. Send them from 1.1.0 on, even though the schema keeps them optional. Extend both contract tests.
- Frontend: `npm run gen:api`. On `routes/(app)/health`, add a "Dead letters" column (count, oldest age, link to `/dlq?account_id=`) and remove `TODO(CCR-003)` in `board.ts`.
- hubmcp / skill: no change.
