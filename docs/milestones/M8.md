## What was built
- **Metrics** (HUB-230): §16.2 set, stage histograms per middleware, cardinality guard, metrics doc in OBSERVABILITY.
- **Tracing** (HUB-231): OTel spans for edge, transform, upstream, outbox, worker and callbacks; trace context carried through the outbox; `traceparent` forwarded only to allowlisted vendors (ADR-0013).
- **Alerts and dashboards** (HUB-232): rules read final outcomes and the DLQ gauge (ADR-0014); queries verified against exported metrics (ADR-0015).
- **PII deletion** (HUB-233): erasure job by subject identifier (ADR-0012).
- **Security hardening** (HUB-234): blocking gosec and govulncheck gates; toolchain pinned to go1.26.10 (go1.26.0 had 36 reachable stdlib vulnerabilities); TLS 1.2 floor on callbacks; body-limit tests through the gateway; DSN password and audit mask key redacted by value; a role-log secret grep across every role.
- **Load and soak** (HUB-235/236): `backend/cmd/hubload` (open loop, ADR-0016), `deploy/load/` harness, pprof on the ops port only (HUB-403, pprof part).
- **Runbooks** (HUB-237): one per alert, an index, and the credential-rotation procedure.
- **Flake fixes** (HUB-238/239, HUB-155/156): golden time-budget retry, atomic config write in the registry watch test, and the ramped drain made to use elapsed time with a one-second catch-up, with a ramp test that checks DESIGN §10.5's properties instead of exact one-second windows.

## Found and fixed
- **Ramped drain lost quota on a slow scheduler pass** (HUB-155/156): it now releases by elapsed time, making up to one second of missed quota, never above the ramped rate.
- **`hub_overhead_ms` was negative on every request** (HUB-405): the deferred call read the clock before the vendor call. Fixed in its own PR, with a test that fails at -20 ms without the fix.
- **gosec ignored `//nolint` annotations** on hubmcp: switched to reviewed `#nosec` lines listed in SECURITY.md §8.1.

## Deviations
1. **Go open-loop load tool instead of k6 or vegeta** (ADR-0016): the tool reads the server-side overhead from the audit ledger and runs at laptop scale.
2. **Alerts read final outcomes and a DLQ gauge** (ADR-0014), and every alert or dashboard query is checked against the exported metric names (ADR-0015).
3. **Trace context across the outbox and to vendors** (ADR-0013): forwarded only to vendors in `HUB_TRACE_FORWARD_VENDORS`; `tracestate` never sent.
4. **The ramp test checks step boundaries** (never ahead of the ramp; owed quota out within one catch-up horizon; backlog empty by 5.8 s), not exact one-second windows, which a delayed scheduler pass on a CI runner broke. Recorded in HUB-156.
5. **The EP-09 ticket range filled up**; follow-ups live in a new epic, EP-13 (HUB-400–429).
