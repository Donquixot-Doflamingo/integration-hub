## What was built
- **Toolchain** (HUB-012): Go 1.27.3, Node 22, Docker + Compose on Colima, golangci-lint 2.15.0 (TECH_SPEC §3).
- **Module and layout** (HUB-020): DESIGN §18.1 packages with `doc.go`. `internal/archtest` enforces the TECH_SPEC §4.1 import table.
- **Makefile and lint** (HUB-021): `build test itest lint fmt bench run mockvendor up down migrate doctor`. Strict golangci-lint v2 config.
- **Compose and migrations** (HUB-023): digest-pinned Postgres 16.15 and Redis 7.4.12. Goose migrations embedded and applied by `hub migrate`.
- **`hub` roles** (HUB-024): gateway, worker, scheduler and admin. Config precedence is flag > `HUB_*` env > default. Secrets come from env only. Graceful shutdown order per the go-architecture skill.
- **Health** (HUB-025): `/healthz` and `/readyz` on the ops port. `NOT_READY` envelope with a `req_` ULID. `internal/core` holds canonical error codes.
- **Redacting logger** (HUB-026): value-based redaction, rotation-safe, about 1 µs per line with 50 secrets.
- **Telemetry** (HUB-027): Prometheus registry (`hub_overhead_ms`, `hub_stage_duration_ms`, `hub_build_info`, Go runtime metrics), OTel server spans that continue the caller's `traceparent`, trace ids in logs.
- **Mock vendor** (HUB-028–030): the full contract, including every fault behaviour and signed inbound webhooks. Tests start it in-process with `mockvendor.Start(t)`.
- **Contract harness** (HUB-031): `internal/testkit/contract` validates live exchanges against `contracts/openapi/*.yaml` with JSON pointers. It has already caught one mock bug.
- **CI** (HUB-022): `.github/workflows/backend.yml` with lint, test, itest, build and smoke-m0.

Coverage (unit, `go test -cover`): roles 92 %, telemetry 90 %, core 90 %, mockvendor 88 %, contract harness 63 %, hub main 56 %.

## Deviations
| # | Deviation | Why | Recorded |
| --- | --- | --- | --- |
| 1 | `go.mod` minimum is Go **1.26**, not 1.25 | goose v3.29 requires 1.26 | TECH_SPEC §3 |
| 2 | `internal/core` (shared leaf) and `internal/testkit` (test-only helpers) added | No import cycles. Mockvendor needs to be importable from tests | ADR-0001 (accepted), TECH_SPEC §4.1, archtest |
| 3 | Metrics use `prometheus/client_golang`; OTel for traces only | TECH_SPEC §13 decision. The go-observability skill assumed OTel metrics and is corrected | TECH_SPEC §13, skill |
| 4 | Mockvendor runs a **dedicated control listener** (:8098) besides the vendor port (:8099); the control API is still also served on the vendor port | `down.mode=refuse` closes the vendor listener, so the control API must stay reachable to recover | F-02 rules |
| 5 | Goose migrations are embedded and run by `hub migrate` (no goose CLI) | The goose CLI pulls every SQL driver into `go.mod`. One binary also runs migrations as a k8s job | TECH_SPEC §14.2 |
| 6 | `/readyz` does not yet check "snapshot loaded" | There is no registry until M1. `roles.Options.ExtraChecks` is the hook | HUB-025 commit, M1 tickets |
| 7 | Contract harness skips example validation | kin-openapi applies 3.0 nullability to examples (false positives). Examples are checked by HUB-015 | TECH_SPEC §13 |
| 8 | One milestone branch with one commit per ticket, instead of one branch per ticket | AGENTS §6 allows `phase-N/slug`. Keeps M0 reviewable as one PR | this summary |
